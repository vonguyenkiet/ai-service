## Các cổng còn phải đạt trước khi merge/đưa vào vận hành

1. CI chạy `ruff check .`, `pytest`, `validate_ai_contract.py` và Docker build **thành công** trên nhánh tích hợp.
2. Xác nhận request/response version 1 bằng contract test giữa ASP.NET backend và Python service, kèm kiểm thử timeout/fallback ở phía backend. Đừng gắn nhãn "end-to-end" khi mới test server đơn lẻ.
3. Chốt và khóa dependency phiên bản (lockfile hoặc constraints) trước khi yêu cầu reproducible production deployment; pin image base theo digest khi release.
4. Chọn model classification/embedding bằng dữ liệu đánh giá chuẩn, có gold set và so sánh baseline; code hiện tại **chưa có model ML thực**.
5. Thêm real backend HTTP adapter, persistence AIAnalysis/AISuggestion, KB embedding + pgvector và flow HITL bằng PR độc lập. Không thêm quyền ghi DB business cho Python service.
6. Bảo đảm secret được quản lý bởi môi trường và AI service không expose internet. Thêm rate limiting/rotation/monitoring trước khi phục vụ tải production.
